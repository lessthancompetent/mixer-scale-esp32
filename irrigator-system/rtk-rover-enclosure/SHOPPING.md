# Shopping list (AliExpress)

Each link is an AliExpress **search**, sorted by number of orders, not a vetted
listing: sellers and listings come and go. Pick a well-sold listing with recent
reviews and check the variant (size, length, voltage) before paying.

Already on hand: simpleRTK2B Micro (F9P, SMA), WildBuckwheat breakout, HC-05,
YH-609 helical antenna, PETG.

Quantities are what the build uses; buy the pack size in brackets.
All fasteners **A2 / 304 stainless**.
